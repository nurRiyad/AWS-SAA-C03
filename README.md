# AWS Exam Prep

A static AWS Certified Solutions Architect – Associate (SAA-C03) study site. It provides exam-specific revision guides and multiple-choice practice for the question banks in `data/exams/`.

## Requirements

- Node.js 24, selected with `nvm use` from the version in `.nvmrc`
- npm

## Run locally

```sh
nvm use
npm install
npm run dev
```

Open the local URL printed by Vite, usually <http://localhost:5174>.

## Project layout

```text
index.html                 Home page entry
public/favicon.svg         Site favicon
src/
  home.js                  Exam catalog behavior
  mcq.js                   Multiple-choice practice behavior
  exam.js                  Revision guide rendering and progress
  storage.js               Browser progress and score storage
  pages/                   MCQ and revision HTML templates
  styles/styles.css        Shared site styles
data/
  exams/<number>/          Exam metadata, question bank, review report, optional guide
  AWS SAA-C03 Dumps.pdf    Source PDF
scripts/                   Question extraction utilities
```

Vite discovers numbered exam folders and builds the catalog from their `exam.json` and question files. Exam routes are generated by `vite.config.js`; do not add a separate exam registry. Each exam has an MCQ route at `/exams/<number>/mcq/`. A revision route at `/exams/<number>/revision/` uses the authored `revision.md` when `revisionFile` is set in the exam metadata. Authored guides currently exist for Exams 1 and 2; other exams use the configured fallback until a guide is added.

## Exam data and revision guides

An exam folder typically contains:

```text
data/exams/2/
  exam.json       # display metadata, question count, and optional guide metadata
  questions.json  # MCQ bank and explanations
  review.json     # extraction or content issues requiring attention
  revision.md     # optional authored revision guide
```

To add or revise a guide, follow Exam 1's `revision.md` structure and use the project skill at `.agents/skills/aws-exam-revision/SKILL.md`. A guide has YAML frontmatter (`title`, `number`, `pointCount`), one numbered study point per question in source order, and a final **The patterns I want you to memorize** section. Each point should state the situation and decision rule, explain why it fits, and provide a concise **Remember:** cue or **Trap:** distinction. Verify questionable answers against current official AWS documentation. Record verified question or explanation errors in that exam's `review.json`; preserve extraction issues and question data.

When adding an authored guide, set `revisionTitle` and `revisionFile` in that exam's `exam.json`. Keep `pointCount` and the number of numbered points aligned with the actual question count. Inspect any flagged source pages in the PDF where possible; mark unresolved content clearly instead of guessing. See `data/extracted/README.md` for extraction workflow details.

The current banks contain 1,019 extracted questions across 16 exams. Most exams contain 65 questions; the final exam is shorter. Question IDs retain the PDF numbering. Source-review questions are identified in the practice view and excluded from scores. Read each exam's `review.json` for its specific extraction or answer-quality flags.

## Progress and scoring

Exam progress and completed scores are saved in browser `localStorage`, scoped to the browser and site address. Clearing site data removes them. Unanswered questions count as incorrect. Questions marked for source review are excluded from the score.

## Build and preview

```sh
npm run build
npm run preview
```

The static site is written to `dist/`.

## Deployment

**Vercel:** Import the repository and use `npm run build` with `dist` as the output directory.

**GitHub Pages:** The included GitHub Actions workflow builds and publishes on pushes to `main`. Enable **Settings → Pages → Build and deployment → GitHub Actions** in the repository. Vite uses relative output paths for project subpaths.
